water mod for polytopia

## Changes

1. custom port: upgraded from a regular port
    - works like a normal port
    - any friendly unit on it can perform "trade" action, consuming itself and granting the owner of the custom port stars.
    - it gives more stars if the unit is an allied unit.
2. scouts cost 3 stars instead of 5, but do not have "scout" ability.
3. bombers have an ability called "heavy" which restricts training them only if the body of water they're in has an ocean tile.
